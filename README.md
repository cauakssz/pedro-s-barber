# Pedro's Barber

A static web interface for a barbershop, featuring a login screen with email and password fields, register and forgot password options. Built as a front-end practice project focused on HTML structure and CSS styling.

## Features

- Login form with email and password fields
- Register and forgot password actions
- Responsive layout
- Custom favicon and image assets

## Technologies

- HTML5
- CSS3
